# 本機模型版 Windows 安裝檔

下載 [LeihuLiantai-localModel-1.4.1-Setup.exe](./LeihuLiantai-localModel-1.4.1-Setup.exe)，雙擊執行。

安裝程式會準備 Python、音訊模型、Ollama 與 Qwen2.5 14B。首次安裝需要網路，建議預留約 20GB 磁碟空間。安裝完成後從桌面捷徑開啟。下載中斷時重新執行安裝檔即可續傳。
